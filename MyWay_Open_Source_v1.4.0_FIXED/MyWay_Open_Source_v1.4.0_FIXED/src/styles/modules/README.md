# CSS do MyWay

Edite os módulos desta pasta. `../app.css` é gerado automaticamente.

Os arquivos `00-legacy-*` até `60-legacy-*` contêm o visual histórico dividido em blocos menores. As mudanças novas ficam separadas:
- `90-theme-contract.css`: tema e contraste.
- `91-dashboard-layout.css`: dashboard drag and drop.
- `92-paged-dialogs.css`: pop-ups sem rolagem.

Use `npm run dev` para ver a alteração automaticamente no editor visual.
