# JavaScript do MyWay

Edite estes arquivos, **não `../app.js`**. `app.js` é um bundle gerado automaticamente.

Ordem prática:
- `00-core-state.js`: estado, utilidades e formulários-base.
- `10-navigation-dashboard.js`: navegação e dashboard histórico.
- `20-life-finance-features.js`: vida, finanças e relatórios.
- `30-productivity-focus.js`: foco e produtividade.
- `40-notes-drag.js`: notas e drag and drop.
- `45-guides-learning.js`: tutoriais e aprendizagem.
- `50-workspaces-mobile.js`: áreas de trabalho e celular.
- `60-appearance-assistant.js`: aparência e assistente interno.
- `70-sync-auth.js`: Supabase, conta e sincronização.
- `80-widgets-resilience.js`: widgets e resiliência.
- `90-release.js`: recursos de release.
- `95-experience-ui.js`: experiência editorial.
- `96-psychoanalysis.js`: Psicanálise.
- `97-theme-contract.js`: contraste e cor global.
- `98-dashboard-layout.js`: organização do dashboard.
- `98-paged-dialogs.js`: pop-ups paginados.
- `99-bootstrap.js`: inicialização. Evite mexer aqui sem necessidade.

Com `npm run dev`, salvar um módulo reconstrói `app.js` automaticamente e atualiza a prévia visual.
