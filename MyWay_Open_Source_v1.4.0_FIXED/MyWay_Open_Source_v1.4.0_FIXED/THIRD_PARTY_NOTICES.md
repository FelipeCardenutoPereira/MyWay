# Avisos de terceiros

O código próprio do MyWay neste repositório é disponibilizado sob a licença MIT indicada em `LICENSE`.

Alguns componentes e dependências mantêm suas próprias licenças, que prevalecem sobre esses componentes:

- `src/assets/mpegts.js` — consulte `src/assets/LICENSE-mpegts.txt`.
- Projeto Android — usa componentes do Android/AndroidX e, conforme a configuração, Google Mobile Ads/UMP. Consulte as licenças das dependências resolvidas pelo Gradle.
- Imagens, áudios, marcas e conteúdos importados devem ser usados apenas quando você possuir direitos ou autorização para distribuí-los.

Chaves privadas de assinatura, senhas, `service_role` do Supabase e outros segredos não devem ser enviados ao GitHub.

## Wallpapers incluídos na v1.2.7

Os três wallpapers em `src/assets/wallpapers/` foram fornecidos pelo usuário para uso no projeto. Antes de redistribuí-los publicamente, confirme que você possui os direitos/licença adequados para essa redistribuição.
