# Android v1.3.7

- UI sincronizada com Windows v1.3.7.
- Package de desenvolvimento mantido: `br.com.myway.open135`, para atualizar a instalação CLEAN anterior.
- versionName no APK: `1.3.7`.
- O build entregue foi reempacotado a partir da base Android estável porque o Gradle deste ambiente tentou baixar sua distribuição e a rede externa estava indisponível.
- `index.html`, `js/app.js` e `styles/app.css` dentro do APK foram comparados por SHA-256 com a UI v1.3.7 e são idênticos.
- Assinatura DEV verificada com `jarsigner`; não é assinatura comercial/Play Store.
